How to use: Drag the String length slider to change the pendulum. Drag the Bob mass slider to change how heavy the bob is. Watch the Period readout — the time for one full swing. Change mass first. Then change length. Which one changes the period?
Notice: changing mass does not change the period — only the string length does. Longer string, slower swing.
